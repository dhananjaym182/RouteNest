快速开始
三步接入：添加账号 → 生成密钥 → 配置客户端
接入步骤
1
添加 Cline 账号
在「凭据 → Cline 账号」中展开「登录与导入」，通过 OAuth、refreshToken 或批量文件添加账号。
2
生成 API Key
前往「密钥与安全」页面生成密钥。如不配置任何密钥，代理允许匿名访问。
3
配置客户端
按下方客户端示例填入 Base URL 与密钥即可。
客户端配置示例
Base URL 中的端口与监听地址以「关于」页 API 地址为准；多 Provider 同名模型可用 模型@Provider名 钉选来源（失败只报错、不悄悄换源）。
Claude Code（Anthropic 协议）
export ANTHROPIC_BASE_URL="http://127.0.0.1:3457"
export ANTHROPIC_API_KEY="<your-api-key>"
claude --model cline-free/glm-5.2
Cline / Roo Code（VS Code 插件）
API Provider: Anthropic
Base URL:  http://127.0.0.1:3457
API Key:   <your-api-key>
Model:     cline-free/glm-5.2
通用 OpenAI 兼容客户端
Base URL: http://127.0.0.1:3457/v1
API Key:  <your-api-key>
Model:    cline-free/glm-5.2
curl 冒烟测试
curl -s http://127.0.0.1:3457/v1/chat/completions \
  -H "x-api-key: <your-api-key>" -H "Content-Type: application/json" \
  -d '{"model":"cline-free/glm-5.2","messages":[{"role":"user","content":"hi"}]}'
