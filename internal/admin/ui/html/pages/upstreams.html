OpenCode Zen 出口代理
发往 OpenCode Zen 的请求可经代理池轮询出口；命中限流时冷却当前出口并自动跳过。支持 http / https / socks5 / socks5h，每行一个，如 socks5://127.0.0.1:1080。
仅决定多个出口代理地址之间的选择；Cline 账号轮询与 Provider 评分在 「路由 → 路由策略」
-
Cline 出口代理
国内直连 Cline 上游会被跨区限制；配置后所有发往 Cline 的请求（对话、登录/令牌刷新、模型同步）经代理池轮询出去。支持 http / https / socks5 / socks5h，每行一个，如 socks5://127.0.0.1:1080。回环 / 内网地址（本机 Ollama 等自定义 Provider）始终直连；未配置时依次尝试环境变量代理、直连。
仅决定多个出口代理地址之间的选择；Cline 账号轮询与 Provider 评分在 「路由 → 路由策略」
