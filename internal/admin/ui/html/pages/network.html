全局出口代理
为所有 Provider 设置统一的出口代理。单个 Provider 可在 Providers 中单独覆盖。
出口配置清单
查看默认出口与服务专属出口；代理地址中的凭据已隐藏。
默认出口代理
所有 Provider 的请求默认使用此代理池，Cline 与 OAuth 的登录、刷新和模型同步也一样。Provider 设置了专属代理（或填「-」直连）时不使用它；OpenCode Zen 使用自己的代理池；localhost 和内网 IP 地址保持直连。未配置时使用环境代理或直连。
仅决定多个出口代理地址之间的选择；Cline 账号轮询与 Provider 评分在 「路由 → 路由策略」
轮询与随机按新建连接选择，而不是按请求。代理连接失败时自动改用列表中的下一个，该代理 30 秒内排到最后。
只有 localhost 和内网 IP 地址直连。用域名访问内网服务（如 ollama.lan）时也会经代理转发，请在该 Provider 的「出口代理」中填「-」设为直连。
