数据与隐私
• 本程序仅在本地运行，默认监听 127.0.0.1:3457，不对外暴露。
• 账号凭据（refreshToken）存储在数据目录的 .routenest-accounts.json（Docker 中位于 /app/data，可用 ROUTENEST_DATA_DIR 配置）中，明文保存，请注意保护。
• 所有 API 请求通过本机代理转发至 Cline 官方服务器，不经过任何第三方。
• 关闭窗口即停止服务，无后台驻留进程。
